# DevHub

DevHub is a developer community application with a React frontend and an Express, Socket.IO, and MongoDB backend.

See [Deployment](DEPLOYMENT.md) for architecture, environment configuration, local verification, database/index preparation, hosting guidance, and release smoke tests. The frontend directory is `fronted/`.

For feature and security guidance, see `INDEX.MD`, `AUTHENTICATION_SECURITY.MD`, and `TESTING_QA.MD` in this directory.
